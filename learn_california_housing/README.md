- My first major milestone in studying Machine Learning. In this project, I aim to combine the EDA steps learned from the Titanic survival prediction project, in combination with the visualization and statistical analysis from the Iris dataset classification to create one big ML first checkpoint project. I also used a pipeline to preprocess features and fitting the models in the same manner to ensure there is no data leakage. Lastly, I had a brief look into the cross validation score for the 2 models that I created. 
- I loosely followed Shubham Kadariya's guide on Medium, the link to the guide is here: https://medium.com/data-and-beyond/i-built-a-machine-learning-model-to-predict-california-house-prices-heres-what-i-discovered-46c4c237f11a. In combination with GeeksforGeeks guide on the same topic, listed here: https://www.geeksforgeeks.org/machine-learning/regression-models-for-california-housing-price-prediction/
- The dataset that I used for this project is from Kaggle, and is listed here: https://www.kaggle.com/datasets/camnugent/california-housing-prices
